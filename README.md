# Estimation of the Effect of Diabetes on Deaths Among COVID-19 Patients: A Systematic Review and Meta-Analysis

### Overview
This repository contains the methodological framework, data extraction records, quality appraisal results, and statistical synthesis outputs for a systematic review and meta-analysis investigating the association between diabetes mellitus and mortality risk in COVID-19 patients.

### Key Findings
* **Included Studies:** 15 cohort and case-control studies covering 68,047,772 patients across 12 countries.
* **Pooled Effect Estimate:** The presence of diabetes was associated with significantly elevated odds of mortality (Pooled OR: 3.33, 95% CI: [2.03, 5.46], p < 0.05).
* **Statistical Model:** Random-effects model (I² = 100%).

### Study Methodology & Tools
* **Protocol Registration:** PROSPERO (CRD42024498934).
* **Reporting Guidelines:** PRISMA 2020 standards.
* **Database Sources:** PubMed, Scopus, Web of Science, and ScienceDirect.
* **Screening & Deduplication:** Rayyan.ai.
* **Quality Assessment:** Newcastle-Ottawa Scale (NOS).
* **Statistical Analysis:** Cochrane Review Manager (RevMan) Version 9.16.0.
